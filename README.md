# 🧠 FastAPI Translation & Summarization API

A simple and fast backend built with **FastAPI** that provides text translation and text summarization through RESTful APIs.

This project is designed to be **lightweight**, **scalable**, and **easy to integrate** with frontend apps (React, mobile apps, etc.).

---

## 🚀 Features

- 🌍 Translate text between multiple languages  
- ✂️ Summarize long texts into concise summaries  
- ⚡ High-performance API powered by FastAPI  
- 📄 Automatic API documentation (Swagger / OpenAPI)  
- 🔌 Easy to integrate with any frontend or service

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```
## Create a virtual environment
```bash
python -m venv venv
```
Activate the virtual environment:

## Linux / macOS
```bash
source venv/bin/activate
```

## Windows
```bash
venv\Scripts\activate
```

## Install dependencies
```bash
pip install -r requirements.txt
```

## ▶️ Running the Project

### Start the FastAPI server:

```bash
uvicorn main:app --reload
```

### The API will be available at:
```bash
http://127.0.0.1:8000
```
